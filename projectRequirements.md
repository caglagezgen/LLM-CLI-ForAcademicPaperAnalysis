#  LLM CLI for Academic Paper Analysis
Please find attached an academic paper that explores the differences between  Large Language Model (LLM) systems and  Agentic AI systems.
# Task
Each student is required to design and implement a  Command Line Interface (CLI) application powered by a Large Language Model (LLM).  
CLI Requirements
Your CLI application must:
- Accept user questions via the command line.
- Interpret and analyse the provided academic paper.
- Generate answers based solely on the content of the paper.
- Avoid using external knowledge beyond the provided document.
### Live Demonstration Requirement
 You must present and demonstrate your CLI application.
The presentation should include:
-  A brief overview of your system
-  A live demonstration of the CLI
-  At least 3–5 example questions about the paper
-  The corresponding answers generated by your system
-  A short explanation of how your system ensures answers are based only on the paper
The demonstration should clearly show that your application is functioning correctly and meeting the assignment requirements.

## Objective: The goal of this assessment is to demonstrate your ability to:
- Apply LLMs to a real-world task
- Extract and utilise relevant information from a structured academic source
- Build an interactive CLI-based application
- To integrate with a locally hosted LLM using Ollama.
- Apply a model such as Llama 3, which is supported by Ollama and suitable for question-answering tasks.
